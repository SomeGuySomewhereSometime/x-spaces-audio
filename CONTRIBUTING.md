# Contributing

Use Node.js 22 or later and run `npm test`. The package has no runtime dependencies.

Keep browser capture independent of application prompts, storage, transcription vendors and X login automation. Add focused synthetic fixtures when changing X metadata mapping. Never submit real cookies, tokens, audio, SDP, private participant data or raw authenticated network captures in issues or pull requests.

When reporting a compatibility problem, include the extension version, browser version, capture mode, browser role in the Space and a minimal sanitized description. Distinguish automated fixture results from a live Space validation.
